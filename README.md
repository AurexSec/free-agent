# free-agent

Минимальный ИИ-ассистент для терминала. Подключается к любому OpenAI-совместимому API,
сохраняет файлы, которые пишет модель (код, сайты, гайды), и превращает Markdown в PDF.

## Что это и чем не является
- Это "руки": чат-цикл + запись файлов в папку `workspace` + PDF.
- "Мозг" (модель) берётся у провайдера. Бесплатные лимиты у провайдеров есть, но они ограничены
  и меняются; доступность из вашей страны проверяйте на сайте провайдера.

## Установка
```
pip install -r requirements.txt
```

## Настройка (PowerShell)
```
$env:AGENT_BASE_URL = "https://openrouter.ai/api/v1"
$env:AGENT_API_KEY  = "ваш_ключ"
$env:AGENT_MODEL    = "имя_модели_из_списка_провайдера"
python agent.py
```
Другие варианты `AGENT_BASE_URL`: `https://api.groq.com/openai/v1`, `https://api.mistral.ai/v1`,
локальный Ollama `http://localhost:11434/v1` (ключ не нужен).

## История и автоподтверждение
- Диалог сохраняется в `workspace/.history.json` и подхватывается при следующем запуске
  (хранятся последние `AGENT_MAX_MESSAGES`, по умолчанию 40). `/reset` очищает историю.
- Запись файлов без вопроса `[y/N]`: запуск с `--yes` или переменная `AGENT_AUTO_YES=1`.
- Ошибки сети, лимиты (429) и сбои сервера (5xx) обрабатываются повторными попытками; неверный ключ
  или модель дают понятное сообщение. Повреждённая история сохраняется как `.history.json.bad`.

## Команды
- `/pdf guide.md` - сделать PDF из Markdown-файла в workspace
- `/files` - список файлов
- `/reset` - очистить диалог
- `/quit` - выход
- запуск с `--yes` - сохранять файлы без вопроса

## Безопасность
Файлы пишутся только внутри `workspace` (выход через `..` и абсолютные пути блокируется).
